# ♟️ AI Chess Game  

A full-featured single and multiplayer chess game developed in **VB.NET**, featuring an AI opponent powered by the **minimax algorithm with alpha-beta pruning**. The project was built as part of my NEA coursework and awarded **Grade A\***.  

---

## ✨ Features  
- **Singleplayer Mode** – play against two AI difficulty levels:  
  - *Easy* (random moves, low strategy)  
  - *Hard* (minimax with alpha-beta pruning for optimal decision-making)  
- **Multiplayer Mode** – play locally against another user with full game logic.  
- **Accounts System** – players can sign up, log in, recover passwords, and track their stats.  
- **Leaderboards** – rankings based on total wins.  
- **Customisation** – choose profile pictures, board colours, and piece styles.  
- **Replays** – save and review previous games to analyse mistakes and improve.  
- **Timer Options** – select timed or untimed games (2, 5, 10, 20 minutes, or unlimited).  
- **Rules & Help** – integrated rules section for new players.  
- **Settings** – change password or delete your account securely.  

---

## 🛠️ Tech Stack  
- **Language:** Visual Basic .NET (VB.NET)  
- **Database:** Microsoft Access  
- **Algorithms:** Minimax with Alpha-Beta Pruning  
- **Design:** OOP with dedicated classes for each chess piece and game logic
